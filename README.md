# SQL Learning

This repository documents my SQL learning journey and practical exercises completed through Codefinity.

The coursework progresses from SQL fundamentals to intermediate data analysis and multi-table queries.

## Topics Covered

### 1. Introduction to SQL
- SELECT statements
- WHERE conditions
- Filtering and sorting
- DISTINCT
- Basic SQL functions

### 2. SQL for Data Analysis
- Aggregate functions
- GROUP BY
- HAVING
- CASE statements
- Data analysis using SQL

### 3. Intermediate SQL
- Subqueries
- Common Table Expressions (CTEs)
- Advanced queries
- Data transformation

### 4. SQL Joins
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Multiple-table joins
- Primary and foreign keys
